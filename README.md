# Kitchora functional website

A four-page static kitchen studio website. Open `index.html` or serve this folder with a static web server.

## Deploy on Vercel

Import this repository, choose **Other** as the framework, keep the root directory as the repository root, leave the build command empty, and use `.` as the output directory.

## Pages

- `index.html`: home and kitchen layouts
- `design.html`: kitchen details and materials
- `calculator.html`: illustrative live cost calculator
- `planner.html`: concept schematic planner

Saved projects and requests use browser storage. Requests download locally and are not delivered to a studio. Bookings, payments and real 3D/CAD functionality require additional services and assets. Internet access is needed for the inherited fonts, Tailwind styles and hosted images.

See [FILE-MAP.md](FILE-MAP.md) for the complete audit and limitations.
